# 証憑研究版の評価JSON集計ツール

保存済みの評価JSONから、項目別の正解率、確認が必要な件数、データの来歴を表示する研究用ツールです。証憑画像を読み取る機能は含みません。

この配布物は、既存の`metric_layers.py`を変更せずに選んだものです。元の研究リポジトリの利用条件は変更していません。

## このPCで例を確認する

Python 3.10以降で、展開したフォルダーから実行してください。追加ライブラリ、APIキー、モデル、フォントの取得は不要です。

```powershell
python -B -X utf8 metric_layers.py examples/synthetic-result.json --json
python -B -X utf8 metric_layers.py examples/synthetic-result.json
```

例は、入力形式と出力を確認するために作った架空の2件です。モデルの試験結果や本人の業務成果を表す数値ではありません。所要時間とモデルの来歴は未入力です。期待する出力は[例の確認事項](examples/EXPECTED.md)を参照してください。

## 入力を確認してから集計する

入力は`summary`を持つJSONオブジェクトです。`summary.cases`または`results`が必要です。項目抽出では`summary.field_accuracy`、照合では`summary.match_accuracy`を使用します。`results`がある場合は配列にしてください。

集計値の一部は入力の`summary`をそのまま表示します。正解ラベルや元画像を検証する処理はなく、件数、率、来歴の完全な整合性検査も行いません。利用者は入力の出どころと計算方法を別途確認してください。個人情報や顧客資料を公開リポジトリへ追加しないでください。

`quality_gate.status`が`human_review_required`なら、結果を確認してください。この状態でもCLIの終了コードは0です。自動処理では終了コードだけで採用せず、JSONの状態を読む必要があります。入力形式の検査は限定的で、すべての不正なJSON構造を扱えるわけではありません。
